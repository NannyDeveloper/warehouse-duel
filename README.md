## 🚀 Запуск игры

### Вариант 1: Прямой запуск (самый простой)
1.  Скачайте или клонируйте репозиторий.
2.  Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari) двойным кликом.

### Вариант 2: Через локальный сервер (рекомендуется)
Некоторые функции (ES6 модули `type="module"`, загрузка ассетов через `fetch`, CORS) могут не работать при открытии файла напрямую (`file://` протокол).

**Python 3:**
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`

**Node.js (npx serve):**
```bash
npx serve .
```

**VS Code:** Установите расширение **"Live Server"**, нажмите правой кнопкой на `index.html` → **"Open with Live Server"**.

## 📦 Сборка и деплой (если применимо)

Если проект использует сборщик (Vite, Webpack, Parcel):

```bash
# Установка зависимостей
npm install

# Режим разработки (с hot-reload)
npm run dev

# Продакшн-сборка (в папку dist/)
npm run build

# Предпросмотр продакшн-сборки
npm run preview
```

**Деплой:** Готовую папку `dist/` (или корень проекта, если без сборки) можно задеплоить на:
*   **GitHub Pages** (Settings → Pages → Deploy from branch)
*   **Netlify** / **Vercel** / **Surge.sh** / **itch.io** (для игр)
