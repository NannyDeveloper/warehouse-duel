# WAREHOUSE DUEL

Динамичный топ-даун шутер для двух игроков на одном клавиатуре: сражайтесь на складе среди ящиков, используйте укрытия и подбирайте случайное оружие, чтобы перехитрить соперника.

![Скриншот игры](screenshot.png)
*(Замените `screenshot.png` на путь к реальному скриншоту геймплея)*

---

## 🎮 Геймплей

Опишите суть игры:
*   **Жанр:** Аркада / Экшен / Локальный мультиплеер (Hotseat)
*   **Цель:** Уничтожить противника 3 раза (лучше из 5 раундов), используя окружение и случайное оружие.
*   **Управление:**
    *   **Игрок 1:** `W` `A` `S` `D` — Движение, `Пробел` — Стрельба / Взаимодействие
    *   **Игрок 2:** `↑` `←` `↓` `→` — Движение, `Enter` / `Ctrl` (правый) — Стрельба / Взаимодействие
    *   `Esc` — Пауза / Меню
*   **Механики:**
    *   **Процедурная генерация арены:** Ящики и укрытия размещаются случайно каждый раунд.
    *   **Система лута:** Разрушаемые ящики выпадают случайное оружиение (дробовик, снайперка, пулемет, плазменная пушка, гранатомет).
    *   **Физика пуль:** Рикошеты от металлических стен, пробитие деревянных ящиков.
    *   **Режим "Внезапная смерть":** Если раунд затягивается, зона начинает сжиматься (газ/огонь с краев).

## 🚀 Запуск игры

### Вариант 1: Прямой запуск (самый простой)
1.  Скачайте или клонируйте репозиторий.
2.  Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari) двойным кликом.

### Вариант 2: Через локальный сервер (рекомендуется)
Некоторые функции (ES6 модули `type="module"`, загрузка ассетов через `fetch`, CORS) могут не работать при открытии файла напрямую (`file://` протокол).

**Python 3:**
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`

**Node.js (npx serve):**
```bash
npx serve .
```

**VS Code:** Установите расширение **"Live Server"**, нажмите правой кнопкой на `index.html` → **"Open with Live Server"**.

## 🛠 Технологии

*   **HTML5** — структура и Canvas API
*   **CSS3** — стилизация UI, меню, адаптивность под разные экраны
*   **JavaScript (ES6 Modules)** — игровая логика, физика, рендеринг, игровой цикл (`requestAnimationFrame`)
*   **Web Audio API** — генерация звуковых эффектов и музыки на лету (без внешних файлов)

## 📁 Структура проекта

```text
.
├── index.html          # Главная точка входа, Canvas контейнер

│   ├── main.js         # Инициализация, загрузка ассетов, запуск GameLoop

│   ├── entities/
│   │   ├── Player.js     # Логика игрока, здоровье, инвентарь
│   │   ├── Bullet.js     # Пули, трассеры, урон
│   │   ├── Crate.js      # Разрушаемые ящики, дроп лута
│   │   └── Weapon.js     # Базовый класс оружия и конкретные реализации
│   ├── systems/
│   │   ├── ParticleSystem.js # Кровь, дым, оболочки, взрывы
│   │   └── AudioSystem.js    # Синтез звуков (sfxr-like)
│   └── utils/
│       ├── Vector2.js    # Векторная математика
│       └── Constants.js  # Конфиг баланса (урон, скорость, КД)
├── assets/               # Пусто (все графика процедурная/Canvas, звук синтезируется)
```

## 🎨 Ассеты и ресурсы

*   **Графика:** 100% процедурная (рисуется через Canvas API: примитивы, градиенты, шейдеры на CPU). Спрайты не используются.
*   **Звук:** Синтезируется в реальном времени через `AudioContext` (осцилляторы, шум, огибающие) — *Zero dependencies, zero assets size*.
*   **Шрифты:** Системные (`monospace`, `sans-serif`) или загружаются через Google Fonts (`Press Start 2P` для ретро-вайба) в `index.html`.
