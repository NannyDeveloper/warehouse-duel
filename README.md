# Моя Стрелялка

## Обзор
Репозиторий содержит 2D аркадную стрелялку, разработанную на Python с использованием библиотеки Pygame. Игрок управляет персонажем, стреляет по врагам, собирает бонусы и проходит через несколько уровней с возрастающей сложностью. В игре реализованы простой интерфейс, система очков, сохранение высокого результата и организованная структура проекта.

## Структура проекта
```
my_game/
│
├─ main.py               # Точка входа в приложение
├─ game.py               # Основная логика игры и управление состоянием
├─ player.py             # Класс игрока (персонаж)
├─ level.py              # Описание уровней и их управление
├─ assets/
│   ├─ images/           # Спрайты персонажей, врагов, предметов, фонов
│   ├─ sounds/           # Звуковые эффекты и музыка
│   └─ fonts/            # Шрифты для UI
├─ config.json           # Файл конфигурации (размеры экрана, цвета, параметры)
├─ requirements.txt      # Список Python‑зависимостей
└─ README.md             # Описание проекта (текущий файл)
```

## Игровой процесс
- **Управление**: стрелки (или WASD) для перемещения, клавиша `Space` для выстрела.
- **Цель**: уничтожать врагов, собирать улучшения, выживать и пройти все уровни.
- **Очки**: начисляются за уничтоженных врагов, сбор предметов и завершение уровней в заданные сроки. Текущий и рекордный результаты сохраняются в `config.json`.
- **Уровни**: несколько уровней, каждый из которых имеет unique‑набор врагов, препятствий и бонусов, а сложность растёт по мере прогресса.

## Технические особенности
- **Модульный дизайн**: логика разделена на отдельные модули (`player.py`, `level.py`, `game.py`, `index.html`), что облегчает поддержку и расширение.
- **Архитектура событий**: основной цикл Pygame обрабатывает ввод, обновляет состояние игры и отвечает за отрисовку, обеспечивая плавную работу.
- **Конфигурация**: все настройки (размеры окна, цвета, параметры физики) читаются из `config.json`, что позволяет менять их без изменения кода.
- **Управление активами**: изображения, звуки и шрифты находятся в директории `assets/`, что делает добавление новых ресурсов простым.
- **Состояние игры**: текущее состояние (меню, игра, пауза, Game Over) управляется через простой менеджер состояний, реализованный в `game.py`.

## Как запустить
1. Убедитесь, что установлен Python 3.8 или выше.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите игру:
   ```bash
   python main.py
   ```
   *Или* откройте `index.html` в современном браузере, если игра реализована через HTML5‑canvas.

4. Следуйте инструкциям на экране, чтобы начать игру.
